# =====================================================================
# AiTeachers 依赖清单（Python 后端）
# ---------------------------------------------------------------------
# 运行环境最低要求（以下均为本机实际运行验证过的版本）：
#   Python  >= 3.11    （验证版本 3.11.0，Windows / Linux 均可运行）
#   Node.js >= 18 LTS  （前端 Vue3 + Vite 4 构建，依赖见 package.json）
#
# 部署步骤：
#   1. python -m venv .venv                     # 创建虚拟环境
#   2. 激活虚拟环境：
#        Windows PowerShell:  .venv\Scripts\Activate.ps1
#        Windows CMD:         .venv\Scripts\activate.bat
#        Linux / macOS:       source .venv/bin/activate
#   3. pip install -r requirements.txt          # 安装后端依赖
#   4. npm install && npm run build             # 前端依赖安装与构建（产物 dist/）
#
# 说明：
#   - 所有版本使用 == 精确锁定（即已验证可运行的最低版本）。langchain 1.x
#     的 create_agent / middleware API 迭代很快，锁定版本可避免上游升级
#     导致服务无法启动。
#   - pywin32 仅 Windows 需要（Word COM 提取评分标准用）；Linux/Docker
#     安装时会自动跳过，评分标准自动降级为内置文本兜底，功能不受影响。
# =====================================================================
